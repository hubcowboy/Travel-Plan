每日行程

Day1｜09-29 抵达｜博多·祇园·中洲

+
15:00 抵达福冈机场，前往酒店入住
🚇 福冈机场 → 地铁空港线祇園站，约12分钟；出站步行5分钟到酒店
17:00 ⭐ Must Go 栉田神社 Kushida Shrine

酒店步行3分钟，傍晚人流较少

18:30 ⭐ Must Go 中洲屋台街 晚餐
🚇 栉田神社步行8分钟，晚餐后步行回酒店

Day2｜09-30 太宰府天满宫

+
08:30 酒店出发前往太宰府
🚇 櫛田神社前站 → 博多站约8分钟；JR/西铁太宰府线 → 太宰府站约16分钟，单程约30分钟
09:30 ⭐ Must Go 太宰府天满宫 Dazaifu Tenmangu
12:00 ☕ Cafe 太宰府兎珈琲 + SAWAWA 抹茶甜品
🟡 Optional 九州国立博物馆

从天满宫步行可达；建议最多选一处博物馆参观。

15:30 返程回博多；晚餐：祇园 Daitoen Hanare Giontei 烧肉
🚇 太宰府JR返回博多，转地铁回祇园酒店

Day3｜10-01 糸岛 Itoshima｜樱井神社 & 二见浦

+
⚠️ 糸岛社区巴士班次极少，约1小时2–3班。建议07:40出门，15:40前从二见浦返程；出行前一天核对巴士时刻表。
07:40 酒店出发
🚇 櫛田神社前站 → 天神站约6分钟；JR筑肥线往唐津方向 → 筑前前原站约45分钟，出站换乘糸岛社区巴士
09:10 ⭐ Must Go 樱井神社 Sakurai Shrine

筑前前原巴士约25分钟抵达

11:30 ⭐ Must Go 二見ヶ浦浜 Futamigaura 夫妇岩
🚇 樱井神社巴士前往二见浦约20分钟
🟡 Optional 七釜洞窟 Nanatsugama

二见浦继续巴士约25分钟；往返额外消耗较多等车时间，时间充裕才考虑。

15:40 巴士返回筑前前原，返程回福冈市区
🚇 筑前前原JR返回天神，地铁回祇园，预计17:30回到市区休整

Day4｜10-02 大濠公园·舞鹤公园·六本松

+
09:00 ☕ Cafe Ohori Terrace 晨间咖啡
🚇 櫛田神社前站七隈线 → 大濠公园站约10分钟
10:00 ⭐ Must Go 大濠公园环湖 + 日式庭园
🟡 Optional 福冈美术馆

大濠公园内步行可达；建议最多选一处博物馆参观。

14:30 ⭐ Must Go 福冈城迹 + 舞鹤公园

大濠公园步行串联，无需再次换乘。

17:00 前往六本松 ☕ Cafe Basking Coffee ropponmatsu
🚇 大濠公园站地铁一站 → 六本松站约3分钟
18:30 六本松/赤坂区域晚餐

+
